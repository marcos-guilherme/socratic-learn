# Cursor Adapter

Opening this repository in Cursor makes the project-level [learning tutor skill](../../.cursor/skills/learning-tutor/SKILL.md) available; no separate installation is required.

The skill loads the universal [agent entry](../../AGENTS.md) and links to the canonical [pedagogy](../../core/pedagogy.md), [session protocol](../../core/session-protocol.md), [assessment](../../core/assessment.md), and [evidence policy](../../core/evidence-policy.md). It only maps those shared contracts to Cursor capabilities.
