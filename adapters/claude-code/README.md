# Claude Code Adapter

Use [CLAUDE.md](CLAUDE.md) as the loader for this repository. In another project, copy it to the project root or include its instructions from that project's existing `CLAUDE.md`, preserving paths to the shared learning environment.

The loader delegates to the universal [agent entry](../../AGENTS.md) and canonical [pedagogy](../../core/pedagogy.md), [session protocol](../../core/session-protocol.md), [assessment](../../core/assessment.md), and [evidence policy](../../core/evidence-policy.md); it does not replace them.
